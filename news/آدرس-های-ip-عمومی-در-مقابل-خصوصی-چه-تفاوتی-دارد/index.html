آدرس های IP عمومی در مقابل خصوصی: چه تفاوتی دارد؟

منبع: Engadget • ۲ آذر • ۰۳:۳۰ • ۲ دقیقه مطالعه
یکی شبکه شما را شناسایی می کند، دیگری دستگاه هایی را که از شبکه شما استفاده می کنند. Calleaume/Getty Images افزودن Engadget به Google: منبع برگزیده Google Discover هر بار که ویدیویی را پخش می‌کنید، مقاله می‌خوانید یا فایل‌های آنلاین دانلود می‌کنید، رابط شبکه و سرور با ا...

یکی شبکه شما را شناسایی می کند، دیگری دستگاه هایی را که از شبکه شما استفاده می کنند.

هر بار که ویدئویی را پخش می کنید، مقاله می خوانید یا فایل های آنلاین دانلود می کنید، رابط شبکه و سرور با استفاده از برچسب های عددی منحصر به فرد به نام آدرس IP با یکدیگر ارتباط برقرار می کنند. هنگامی که اتصال اینترنتی به دست می آورید، ISP شما یک آدرس IP عمومی منحصر به فرد را به پورت WAN روتر شما اختصاص می دهد. آدرس IP عمومی چیزی است که به شما امکان می دهد به اینترنت و اینترنت برای پیدا کردن شما دسترسی داشته باشید.

همه ابزارهای مختلف متصل به شبکه خانگی شما مانند تلفن ها، رایانه ها و سخت افزار خانه هوشمند از طریق آدرس های IP خصوصی به روتر شما متصل می شوند تا آدرس عمومی اختصاص داده شده به روتر شما. دستگاه‌های روی آدرس‌های IP خصوصی می‌توانند با یکدیگر ارتباط برقرار کنند، اما نمی‌توانند مستقیماً به اینترنت دسترسی داشته باشند. آنها باید به یک روتر تکیه کنند. به طور مشابه، دستگاه های خارج از شبکه خصوصی نمی توانند با کسانی که از آدرس IP خصوصی استفاده می کنند ارتباط برقرار کنند. به همین دلیل است که همسایه شما نمی تواند درخواست چاپ را برای چاپگر خانگی شما ارسال کند.

هنگام تلاش برای درک آدرس IP عمومی در مقابل خصوصی، می توانید اولی را به عنوان آدرس خانه خود و دومی را به عنوان شماره آپارتمان در نظر بگیرید. به هر دستگاه متصل به روتر شما یک آدرس IP خصوصی منحصر به فرد اختصاص داده می شود. دانستن نحوه یافتن آدرس‌های IP دستگاه‌های متصل شما می‌تواند به ساده‌سازی تلاش‌های عیب‌یابی در صورت شروع به کار شبکه خانگی کمک کند.

سریعترین راه برای یافتن آدرس IP عمومی شما از طریق یک ابزار بررسی IP آنلاین مانند WhatIsMyIPAddress و ifconfig.me است. شما می توانید از هر دستگاهی که به روتر خود متصل است برای این فرآیند استفاده کنید تا زمانی که قابلیت دسترسی به یک مرورگر وب را داشته باشد. برای شناسایی آدرس‌های IP خصوصی، می‌توانید از کنترل پنل روتر خود برای مشاهده لیست دستگاه‌های متصل به شبکه خانگی خود، از جمله آدرس‌های IP خصوصی آنها استفاده کنید. با این حال، این روش ممکن است برای شناسایی آدرس IP مربوط به چه دستگاهی کافی نباشد، زیرا همه سازندگان دستگاه ها نام میزبان را ندارند.
