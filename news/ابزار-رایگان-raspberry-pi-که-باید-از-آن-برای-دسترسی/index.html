ابزار رایگان Raspberry Pi که باید از آن برای دسترسی از راه دور استفاده کنید

منبع: Engadget • ۱ آذر • ۰۱:۱۵ • ۲ دقیقه مطالعه
با استفاده از این ابزار مفید از ارسال پورت ها خودداری کنید. Pazargic Liviu/Shutterstock افزودن Engadget به Google: منبع ترجیحی Google Discover دسترسی از راه دور به Raspberry Pi برای پروژه‌های خانگی بسیار ارزشمند است، زمانی که نمی‌توانید مستقیماً به دستگاه خود دسترسی پید...

با استفاده از این ابزار مفید از ارسال پورت ها خودداری کنید.

دسترسی از راه دور به Raspberry Pi برای پروژه های خانگی بسیار ارزشمند است، زمانی که نمی توانید مستقیماً به دستگاه خود دسترسی پیدا کنید. در گذشته، ورود به سیستم Pi به معنای راه‌اندازی یک سرویس VNC یا تونل‌سازی SSH بود که هر دو به ارسال پورت نیاز دارند. این می تواند برای مبتدیان یک دردسر و یک خطر امنیتی بالقوه برای پروژه های خاص باشد. خوشبختانه، راه بهتری برای دسترسی به رزبری پای خود از راه دور بدون پورت های بحث و جدل وجود دارد.

Raspberry Pi Connect برنامه ای است که توسط Raspberry Pi ایجاد شده است که به شما امکان می دهد با واحد Pi خود از طریق اینترنت از خارج از شبکه خود ارتباط برقرار کنید. این راحت است، نیازی به ارسال پورت ندارد و به شما امکان می دهد زمانی که خارج از شبکه خود هستید به Pi خود دسترسی داشته باشید. بهترین بخش این است که Connect به طور خودکار با دستگاه شما کار می کند اگر از Bookworm یا نسخه های جدیدتر استفاده می کند. دستگاه‌های قدیمی‌تر گزینه‌های محدودی با Connect دارند، اما تا زمانی که از Pi OS یا نوع Lite آن استفاده می‌کنید، می‌توانید آن را به سرعت اجرای چند دستور در ترمینال SSH تنظیم کنید.

Raspberry Pi Connect از WebRTC استفاده می کند، یک اتصال همتا به همتا بین دو مرورگر وب که از طریق یک تونل امن اجرا می شود. این به هیچ نرم افزار شخص ثالثی در واحد Pi شما نیاز ندارد و ماهیت امن آن به آن اجازه می دهد فایروال های سختگیرانه و NAT های محدود شده را دور بزند. از آنجایی که از طریق اینترنت اجرا می شود، برای استفاده از آن به دسترسی به اینترنت و یک حساب کاربری Raspberry Pi Connect نیاز دارید.

اتصال دو ویژگی کلیدی را ارائه می دهد: اشتراک گذاری صفحه نمایش و پوسته از راه دور. پوسته از راه دور به عنوان یک ترمینال SSH عمل می کند که در مرورگر شما اجرا می شود و آن را برای نظارت یا اجرای دستورات از راه دور ایده آل می کند. اشتراک‌گذاری صفحه به شما امکان می‌دهد مرورگر خود را به یک دسکتاپ از راه دور برای Pi خود تبدیل کنید. اشتراک‌گذاری صفحه از طریق یک جلسه Wayland اجرا می‌شود که از منابع Pi استفاده می‌کند و به یک جلسه دسکتاپ فعال نیاز دارد. پوسته از راه دور نمی کند. اگر از یک مدل قدیمی Pi استفاده می کنید، اگر می خواهید از ویژگی اشتراک صفحه نمایش Connect استفاده کنید، حتما سیستم عامل Pi آن را به روز کنید. Pi OS Lite و X11 با این ویژگی سازگار نیستند.
